# RK Tours & Travels 🌍

A static travel website built with **HTML, CSS, and JavaScript** for RK Tours & Travels.

## 🚀 Live Demo

Deploy on GitHub Pages:
```
https://<your-username>.github.io/RK-Tours-Travels/
```

## 📁 Project Structure

```
RK-Tours-Travels/
├── index.html          # Home page
├── trips.html          # Trip details (Mumbai, Goa, Kashmir)
├── packages.html       # Pricing packages
├── documents.html      # Required documents & checklist
├── contact.html        # Contact form & info
├── css/
│   ├── style.css       # Main styles
│   └── responsive.css  # Mobile responsive styles
├── js/
│   ├── script.js       # Navigation, scroll effects
│   └── validation.js   # Contact form validation
├── images/             # All images
└── README.md
```

## 🛠️ Tech Stack

- **HTML5** — Structure
- **CSS3** — Styling & Animations
- **JavaScript (ES6)** — Interactivity
- **Font Awesome** — Icons
- **Google Fonts** — Poppins font family

## ✨ Features

- Responsive design (mobile, tablet, desktop)
- Mobile hamburger navigation menu
- Smooth scroll-to-top button
- Fade-in scroll animations
- Contact form with validation
- Pre-travel document checklist (saves progress)
- Trip detail pages with itineraries
- Package pricing comparison

## 📱 How to Deploy on GitHub Pages

1. Create a new repository on GitHub
2. Push this project to the `main` branch
3. Go to **Settings → Pages**
4. Select **Deploy from a branch**
5. Choose `main` branch and `/ (root)` folder
6. Click **Save**
7. Your site will be live in a few minutes!
